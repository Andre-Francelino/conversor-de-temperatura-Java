# 🌡️ Conversor de Temperatura em Java

Aplicação desenvolvida em **Java** para converter temperaturas entre as escalas Celsius e Fahrenheit por meio de uma interface de texto no terminal.

O projeto foi criado com o objetivo de praticar conceitos fundamentais de lógica de programação e aprofundar o conhecimento sobre métodos, estruturas condicionais e entrada e saída de dados em Java.

## 📌 Funcionalidades

- 🌡️ Conversão de Celsius para Fahrenheit.
- 🌡️ Conversão de Fahrenheit para Celsius.
- ⌨️ Entrada de dados pelo teclado.
- 📋 Menu interativo para selecionar o tipo de conversão.
- ✅ Exibição da temperatura original e do resultado convertido.
- ⚠️ Tratamento de opções inválidas no menu.

## 🧮 Fórmulas utilizadas

**Celsius para Fahrenheit**

Fórmula: `F = (C × 9 / 5) + 32`

**Fahrenheit para Celsius**

Fórmula: `C = (F - 32) × 5 / 9`

Onde:
- `C` representa a temperatura em graus Celsius.
- `F` representa a temperatura em graus Fahrenheit.

## 🛠️ Tecnologias e conceitos

- **Java** — linguagem utilizada no desenvolvimento.

## ▶️ Como executar o projeto

### Pré-requisitos

- JDK (Java Development Kit) instalado.
- Editor de código ou IDE com suporte a Java, como Visual Studio Code, IntelliJ IDEA ou Eclipse.

### 1. Clone o repositório

```bash
git clone https://github.com/Andre-Francelino/conversor-de-temperatura-Java.git
```

### 2. Acesse a pasta do projeto

```bash
cd conversor-de-temperatura-Java
```

### 3. Abra o projeto na sua IDE

Importe ou abra a pasta do projeto no editor de sua preferência e execute a classe Java que contém o método `main`.

Caso prefira executar pelo terminal, entre na pasta que contém o arquivo `.java` e compile e execute a classe principal:

```bash
javac NomeDaClasse.java
java NomeDaClasse
```

Substitua `NomeDaClasse` pelo nome real da classe principal, sem a extensão `.java`.

## 💻 Exemplo de utilização

Ao iniciar o programa, o usuário visualizará um menu semelhante a este:

```text
Escolha uma opção:

1 - Converter temperatura de Celsius para Fahrenheit.
2 - Converter temperatura de Fahrenheit para Celsius.
```

Após selecionar uma opção, o programa solicita a temperatura desejada, realiza a conversão e exibe o resultado no terminal.
